Десктопный дом для кодинг-агентов.

Откройте проект, опишите задачу, и один агент или целый рой работает в изолированных git worktree. Вы смотрите на понятные карточки разрешений и аккуратный diff, а не на стену логов.

01Что умеет

Спокойно на поверхности, глубина по запросу.

Octopus для тех, кому нужен результат, а не внутренности. Всё техническое в одном клике и не лезет в глаза.

01●

Чат с агентом

Работайте в папке проекта обычным разговором. Шаги инструментов свёрнуты, пока вам не понадобятся детали.

02●

Рой агентов

Запускайте несколько агентов параллельно, у каждого свой git worktree, поэтому они не мешают друг другу.

03●

Контрольные точки и изменения

Видно, что именно тронул агент. Смотрите diff и делайте коммит, не выходя из приложения.

04●

Карточки разрешений

Перед чем-то рискованным приходит короткая карточка человеческим языком: что агент хочет сделать и зачем.

05●

Правила и инструкции

Объясните агенту, как устроен проект: общие правила и правила для проекта, которым он следует каждый раз.

06●

Терминал, вход, бюджет

Встроенный терминал и просмотр файлов, вход через подписки, которые у вас уже есть, или свои ключи в связке ключей ОС, и счётчик расходов, который держит траты на виду.

02Как это работает

От идеи до коммита за три шага.

1

Откройте проект

Выберите папку. Octopus запустит агента прямо в ней и покажет его состояние с первого взгляда.

2

Опишите задачу

Сначала агент предложит план. Одобрите его, поправьте или разделите работу на рой.

3

Проверьте и закоммитьте

Посмотрите изменения, используйте контрольные точки, если что-то пошло не так, и делайте коммит из приложения.

03Запуск

Скачайте и начните за минуту.

Движок агента уже внутри, ставить больше ничего не нужно. Войдите через подписку, которая у вас уже есть, или добавьте ключ провайдера. Новые версии приходят обновлением прямо в приложении.

  1. 01●

    Скачайте

    Образ .dmg для Mac на Apple Silicon. Перетащите Octopus в «Программы».

  2. 02●

    Откройте один раз

    Сборка пока не подписана Apple. Если macOS не даёт её открыть, зайдите в Системные настройки → Конфиденциальность и безопасность и нажмите Всё равно открыть.

  3. 03●

    Подключите модель

    Войдите через подписку или вставьте ключ провайдера. Ключи хранятся в связке ключей ОС.

Хотите собрать сами?

Нужны Rust, Node.js 20.19+ и движок агента oh-my-pi.

# движок агента
$ brew install omp
# приложение
$ git clone https://github.com/SkvorikovCode/Octopus-AI.git
$ cd Octopus-AI
$ npm install
$ npm run tauri dev

Пока публикуются только сборки для Apple Silicon. Что-то пошло не так? Напишите в issues.

04Поддержка

Делается в открытую. На деньги тех, кто пользуется.

Octopus под Apache-2.0 и таким останется. Поддержка идёт на сам проект, без посредников.

Серверы для кодинг-агентов

Сегодня Octopus работает на ключах и подписках, которые у вас уже есть. Пожертвования пойдут на следующий шаг: серверы, собранные под кодинг-агентов, чтобы никому не приходилось зависеть от чужой подписки.
