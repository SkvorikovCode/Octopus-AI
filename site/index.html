A desktop home for coding agents.

Open a project, describe what you want, and watch one agent, or a whole swarm, do the work in isolated git worktrees. You review plain-language permission cards and a clean diff instead of a wall of logs.

Download for macOSStar on GitHub

Apple Silicon · macOS 11+ · free and open source

01What it does

Calm on the surface, depth on demand.

Octopus is for people who want the result, not the plumbing. Everything technical is one click away and never in your face.

01●

Chat with an agent

Work in your project folder in plain conversation. Tool steps stay collapsed until you want the detail.

02●

Agent swarm

Run several agents in parallel, each in its own git worktree, so they never step on each other’s files.

03●

Checkpoints and changes

See exactly what the agent touched, review the diff, and commit without leaving the app.

04●

Permission cards

Before anything risky happens you get a short card in plain language: what the agent wants to do, and why.

05●

Rules and instructions

Teach the agent how your project works with general and per-project rules it follows every time.

06●

Terminal, sign-in, budget

A built-in terminal and file viewer, sign-in with the subscriptions you already have or your own keys in the OS keychain, and a spend meter that keeps costs visible.

02How it works

From idea to commit in three steps.

1

Open a project

Pick a folder. Octopus starts the agent right there and shows its state at a glance.

2

Describe the task

The agent proposes a plan first. Approve it, adjust it, or split the work across a swarm.

3

Review and commit

Check the changes, use checkpoints if something goes sideways, and commit from the app.

03Get started

Download it and start in a minute.

The agent engine is bundled, so there is nothing else to install. Sign in with a subscription you already have or add a provider key. New versions arrive as updates inside the app.

  1. 01●

    Download

    A .dmg for Apple Silicon Macs. Drag Octopus into Applications.

  2. 02●

    Open it once

    The build is not signed by Apple yet. If macOS refuses to open it, go to System Settings → Privacy & Security and press Open Anyway.

  3. 03●

    Connect a model

    Sign in with a subscription or paste a provider key. Keys stay in the OS keychain.

Download for macOSAll releases

Prefer to build it yourself?

You need Rust, Node.js 20.19+ and the oh-my-pi agent engine.

# agent engine
$ brew install omp
# the app
$ git clone https://github.com/SkvorikovCode/Octopus-AI.git
$ cd Octopus-AI
$ npm install
$ npm run tauri dev

Only Apple Silicon builds are published so far. Something went wrong? Open an issue.

04Support
